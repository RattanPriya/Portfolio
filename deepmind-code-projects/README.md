# DeepMind Code PM Portfolio

Small, role-targeted projects for a Senior Product Manager, Code role. The projects emphasize AI coding strategy, developer-agent workflows, eval design, data strategy, and model-quality tradeoffs.

## Projects

1. `code-eval-lab` - a Python harness for evaluating code-generation outputs across correctness, style, safety, and developer usability.
2. `dev-agent-workflow-sim` - a simulator for an agentic developer workflow that triages failing tests and recommends next actions.
3. `code-data-strategy-kit` - a data strategy toolkit for prioritizing coding use cases, collection plans, and evaluation rubrics.

These are intentionally compact, readable artifacts: enough implementation to be credible, plus enough product framing to show how the work would scale into a Gemini Code roadmap.
