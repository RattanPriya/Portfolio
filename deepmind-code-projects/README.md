# Code Product Concepts

Senior-PM portfolio artifacts for AI-assisted software development.

The thesis: AI coding tools are winning mindshare when they own the end-to-end developer loop: understand a codebase, plan work, edit files, run tests, create PRs, remember team conventions, and work across surfaces. The next product frontier is making those systems trustworthy inside real teams: connected to product context, CI, code review, release risk, and organization-specific standards.

## Portfolio concepts

### 1. Code Eval Studio

An eval workbench for AI coding models and developer agents. It lets teams define task families, run model variants, review human preference data, and track regressions across correctness, style, safety, usefulness, and trust.

Path: [`code-eval-lab`](code-eval-lab)

### 2. CI Doctor

An agentic CI failure workflow that watches test failures, distinguishes flaky vs real regressions, proposes root causes, drafts minimal patches, reruns tests, and opens PRs with evidence.

Path: [`dev-agent-workflow-sim`](dev-agent-workflow-sim)

### 3. Workspace-to-Code Graph

A system that turns product docs, meeting notes, customer threads, spreadsheets, issue trackers, and repository history into implementation plans, tests, PRs, and long-lived team memory.

Path: [`code-data-strategy-kit`](code-data-strategy-kit)

## What these artifacts show

- Product strategy for coding agents, not just implementation snippets.
- Eval/data thinking for model improvement loops.
- Trust and control surfaces for enterprise adoption.
- Ecosystem insight: product context, CI, repository history, observability, and team memory as developer context.
- MVP thinking with measurable adoption, quality, and reliability metrics.
